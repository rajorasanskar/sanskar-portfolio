# Sanskar Rajora - Full Stack Developer Portfolio 🚀

Welcome to my personal portfolio! This project showcases my skills in modern web development, focusing on performance, creativity, and interactive user experiences.

## 🌟 Features
- **Interactive 3D Elements**: Using Three.js to create immersive environments.
- **GSAP Animations**: Fluid, high-performance transitions for a premium feel.
- **Responsive Design**: Tailored for all screen sizes, from mobile to ultra-wide displays.
- **Modern Tech Stack**: Built with React, TypeScript, and Vite.

## 🛠️ Tech Stack
- **Frontend**: React, TypeScript, HTML5, CSS3, JavaScript
- **Animations/3D**: GSAP, Three.js, WebGL
- **Tools**: Vite, ESLint, Git

## 🚀 Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/rajorasanskar/sanskar-portfolio.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
